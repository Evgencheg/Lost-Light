[color=#ffffff]Параметры панели создания объектов[/color]
[color=#a4885c]Default[/color] создаёт мелкие объекты вроде кружек без выравнивания, а блочные объекты вроде стен выравнивает по сетке.
[color=#a4885c]PlaceFree[/color] создаёт все объекты без выравнивания.
[color=#a4885c]PlaceNearby[/color] ограничивает радиус создания примерно 2 тайлами.
[color=#a4885c]SnapgridCenter[/color] выравнивает объект по центру тайла.
[color=#a4885c]SnapgridBorder[/color] выравнивает объект по границе тайла.

[color=#ffffff]Параметры выравнивания по сетке[/color]
[color=#a4885c]AlignSimilar[/color] притягивает объект к похожим объектам. Сейчас не работает.
[color=#a4885c]AlignTileAny[/color] выравнивает объект по сетке.
[color=#a4885c]AlignTileEmpty[/color] целевой тайл должен быть пустым
[color=#a4885c]AlignTileNonDense[/color] в целевом тайле не должно быть коллайдеров.
[color=#a4885c]AlignTileDense[/color] в целевом тайле должны быть коллайдеры.
[color=#a4885c]AlignWall[/color] притягивает к вертикальным полутайлам.
[color=#a4885c]AlignWallProper[/color] притягивает объект к середине краёв тайла
