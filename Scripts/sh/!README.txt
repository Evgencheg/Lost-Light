buildAllDebug
    Собирает все проекты в отладочной конфигурации (debug)
buildAllRelease
    Собирает все проекты в релизной конфигурации (release)
buildAllTools
    Собирает все проекты в конфигурации tools

Разница между debug и release простая: в debug-сборке ведётся разработка, а release — это то, на чём работает настоящий сервер.
Release-сборка содержит различные оптимизации, а debug-сборка — инструменты для отладки.
Если вы занимаетесь маппингом, используйте release или tools сборку: она работает плавнее и реже падает.

runQuickAll
    Запускает клиент и сервер без сборки
runQuickClient
    Запускает клиент без сборки
runQuickServer
    Запускает сервер без сборки

runTests
    Запускает юнит-тесты, проверяет, что различные системы на C# работают как задумано
runTestsIntegration
    Запускает интеграционные тесты, проверяет, что различные системы на C# работают как задумано
runTestsYAML
    Запускает YAML-линтер и находит в YAML-файлах ошибки, которые вы, скорее всего, иначе бы не заметили
